# 🎵 SHADOW CHEATS MUSIC — Setup & User Manual

Welcome to **SHADOW CHEATS MUSIC**, a premium, high-fidelity Discord music bot specialized in streaming high-quality music 24/7. Fully unlocked with lifetime free premium features, interactive control panels, and advanced equalizers.

---

## 🔑 1. How to Setup (A-to-Z Guide)

Before starting the bot, you must register it on Discord's developer site:

1.  Open the **[Discord Developer Portal](https://discord.com/developers/applications)**.
2.  Click **New Application** at the top right, name it (e.g. *SHADOW CHEATS MUSIC*), and click **Create**.
3.  Go to the **Bot** tab on the left sidebar:
    *   Click **Reset Token** and copy the long token code. **Save this token; you will need it next!**
4.  Scroll down to the **Privileged Gateway Intents** section and toggle **ON** these three options:
    *   `Presence Intent`
    *   `Server Members Intent`
    *   `Message Content Intent`
5.  Click **Save Changes**.

---

## ⚙️ 2. Configure the Bot
Open [config.json](file:///config.json) in your folder with any text editor (like Notepad) and edit the settings:

```json
{
  "token": "YOUR_DISCORD_BOT_TOKEN_HERE",
  "prefix": ".",
  "owner_ids": []
}
```
*   Replace `YOUR_DISCORD_BOT_TOKEN_HERE` with the token you copied from the Developer Portal.
*   Put your Discord User ID inside the `owner_ids` brackets (e.g., `[123456789]`) if you want dev privileges.

---

## 🚀 3. Run the Bot (Windows)
1.  Download and install **[Python 3.10 or 3.11](https://www.python.org/downloads/)**. Make sure to check the box **"Add Python to PATH"** during setup.
2.  Double-click **`install.bat`** to install all required dependencies automatically.
3.  Double-click **`run.bat`** to start your bot! Keep the console window open to keep the bot online.

---

## 🔗 4. Invite the Bot
Once the bot window prints `🎵 SHADOW CHEATS MUSIC Online`:
1.  Type `/invite` or `.invite` in any channel of a server the bot is in.
2.  Click the link generated by the bot to authorize and add it to your server!

## 🎛️ 5. Command Reference

The bot supports both **Slash Commands** (`/`) and **Prefix Commands** (default: `.`).

### Music & Playback
*   `/play <query>` | `.play <query>` — Play a song, playlist, YouTube URL, or Spotify link.
*   `/nowplaying` | `.np` — Open the active visual control panel with interactive buttons.
*   `/panel` | `.panel` — Reopen the interactive player dashboard.
*   `/pause` | `.pause` / `/resume` | `.resume` — Pause or resume playback.
*   `/skip` | `.skip` / `/voteskip` | `.voteskip` — Skip the current track.
*   `/queue` | `.queue` — Show the queue with interactive page-turning buttons.
*   `/clear` | `.clear` — Clear the queue.
*   `/stop` | `.stop` — Disconnect the bot and clear the current queue.

### Audio Effects & Custom Filters
*   `/equalizer <preset>` | `.eq <preset>` — Apply equalizer presets: `classical`, `jazz`, `metal`, `rock`, `vocal`, `electronic`, `bassboost`, `flat`.
*   `/radio <station>` | `.radio <station>` — Stream 24/7 live lofi or chill radio streams.
*   `/volume [1-200]` | `.volume [level]` — Change output volume.
*   `/speed <0.5-2.0>` | `.speed <multiplier>` — Speed up or slow down playback.
*   `/pitch <0.5-2.0>` | `.pitch <multiplier>` — Shift audio pitch.
*   `/filter <filter>` — Apply sound filters: `lofi`, `nightcore`, `8d`, `vaporwave`, `slowmo`, `earrape`, `pop`.
*   `/clearfilter` — Reset all active filters back to default.

### Custom Saved Playlists
*   `/pl-create <name>` — Create a custom playlist.
*   `/pl-savecurrent <name>` — Save the current track to your playlist.
*   `/pl-play <name>` — Queue up and play all tracks from your playlist.
*   `/pl-delete <name>` — Delete a saved playlist.
*   `/fv-save` / `/fv-play` — Save current song to or play your `Favorite` playlist.
