Overview
🚀 Getting Started

Adding VEYRA to your Discord server takes under 30 seconds. Follow these 3 easy steps to arm your community:

1. Invite the Bot

Click the official OAuth2 authorization link: Invite VEYRA to Server ↗. Grant Administrator permissions so VEYRA can scan audit logs and intercept raid attacks.

2. Position the VEYRA Role

In your Discord Server Settings → Roles, ensure the VEYRA role is dragged near the top (above regular members and moderators). Discord hierarchy requires VEYRA to sit above any roles it is protecting or managing.

3. Run Initial Setup

Execute /scan in any private admin channel. VEYRA will audit your current role hierarchy, channel permissions, and alert you of any security vulnerabilities in under 0.04ms.

📝 Frequently Asked Questions

Answers to the most common setup and operation questions.

1. The bot won't answer me! What do I do?
It could be a channel permissions issue! Make sure VEYRA has the "View Channel", "Send Messages", and "Embed Links" permissions in that channel. Also verify slash commands are enabled in your server integration settings.
2. The bot says I don't have permission, what gives?
You need either the Administrator permission in Discord or server ownership to configure security modules. You can also whitelist trusted staff accounts using /whitelist add_user.
3. How fast does the anti-nuke defense respond?
VEYRA operates a real-time gateway listener that intercepts mass channel deletions, role stripping, and webhook modifications in under 0.04ms, instantly revoking rogue administrator tokens.
4. Can I customize ticket panels and embeds?
Yes! Run /setup panel to spawn drag-and-drop ticket buttons, configure staff claim queues, and generate instant downloadable HTML transcripts.

🛡️ Privacy Policy
LAST UPDATED: OCTOBER 2026

At VEYRA, protecting your privacy and Discord server data is our fundamental commitment. This Privacy Policy outlines what information we collect, how it is processed, and your rights.

1. Data We Collect

To deliver security, anti-nuke shielding, and ticketing functionality, VEYRA processes:

  • Discord Guild IDs, Channel IDs, Role IDs, and User IDs required for configuration.
  • Audit log metadata strictly for intercepting unauthorized nuke or raid events.
  • Ticket transcripts generated only when explicit close actions are triggered by moderators.

2. How We Use Data

Data collected is used exclusively for executing configured bot commands and stopping malicious server raids. We never sell, lease, or monetize your server data, user profiles, or message content to third parties.

3. Data Retention & Deletion

When VEYRA is removed from a Discord server, server-specific configurations and active security locks are purged upon request. You may request complete data purging by contacting our support desk.

VEYRA offers a REST/JSON API for developers to programmatically interact with guild security and statistics.

Base URL

https://veyra-bot.vercel.app/api/v1/...

Authentication

All API authentication is verified via bearer tokens passed in the Authorization HTTP header:

Authorization: Bearer YOUR_API_KEY

Rate Limiting

Rate limiting prevents abuse and ensures equal resource distribution. Standard tier is limited to 60 requests per minute. Hitting the limit returns an HTTP 429 Too Many Requests response.
