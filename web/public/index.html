FREQUENTLY ASKED QUESTIONS

Is the bot online 24/7?

Yes, VEYRA operates on high-availability cloud infrastructure with a guaranteed 99.9% uptime. System restarts and updates are executed hot with zero service interruption.

How does the Anti-Nuke system prevent malicious admins?

VEYRA intercepts audit log events in real-time. If an admin account deletes multiple channels, bans members, or removes roles beyond your specified threshold, the bot instantly strips their permissions or bans them, and restores the deleted items.

Can I whitelist my co-owners?

Absolutely. You can whitelist trusted administrators to bypass all anti-nuke limits and modifications using the `/whitelist` command or directly through the web dashboard.

What is the difference between Anti-Nuke and Anti-Raid modules?

Anti-Nuke protects the server from internal administrative threats (rogue staff abusing roles/channels), while Anti-Raid secures the guild against external threats (mass join bots, spammers, and raid vectors joining the guild).

How does Webhook Protection secure my integrations?

VEYRA monitors webhook creations and modifications. If any unauthorized user or bot tries to make a webhook to spam channels, VEYRA instantly deletes the webhook and puts the creator on lock rules.

How does the real-time Audit Weblogs system sync?

Every security event intercepted by the Python bot is logged in the central SQLite database and immediately pushed to the Node web server, synchronizing with your dashboard's active Audit logs stream within milliseconds.

Can I build custom embeds using the Embed Builder?

Yes, the Embed Builder tab allows you to configure embed descriptions, authors, titles, colors, and fields, saving them directly to be broadcasted to specified guild channels by the bot.

What does "Beast Mode" do?

Beast Mode is an aggressive anti-nuke status that locks down ALL administrative modifications. Even whitelisted members will require double-auth confirmation prompts to delete channels or modify roles.

How does the Invite Tracker keep track of invites?

The Python bot caches all active guild invites. When a new member joins, VEYRA fetches invites again, identifies the invite code whose "uses" count incremented, and logs the inviter ID in database audit histories.

Is my server configuration stored securely?

Yes. All whitelists, rate limits configurations, audit tables, and prefix variables are stored inside a secured SQLite local database protected from external packet inspectors.

                                                         Panel Editing Guide
                                                    

                                                    

                                                        
Welcome to the Panel Editor! This guide will help you create and customize your support panel. Click on any element in the preview to start editing.

                                                        
                                                        Understanding Your Panel
                                                        Your panel is made up of three types of components:
                                                        
    
                                                            
  • Embeds - The message cards that display your panel content (title, description, images, colors)
    • 
                                                            
  • Buttons - Clickable buttons that open tickets/applications or link to external URLs
    • 
                                                            
  • Select Menus - Dropdown menus with multiple options for users to choose from
    • 
                                                        


                                                        Editing Embeds
                                                        Click on any embed in the preview to edit it. You can customize:
                                                        
    
                                                            
  • Title & Description - The main text content of your embed
    • 
                                                            
  • Color - The colored accent bar on the left side of the embed
    • 
                                                            
  • Author - Optional header with name and small icon above the title
    • 
                                                            
  • Footer - Optional text and icon at the bottom of the embed
    • 
                                                            
  • Image - A large image displayed within the embed
    • 
                                                            
  • Thumbnail - A small image in the top-right corner
    • 
                                                            
  • URL - Makes the title clickable as a link
    • 
                                                        

                                                        
You can have up to 10 embeds. Use the arrows or drag handles to reorder them.


                                                        Working with Buttons
                                                        Buttons are the primary way users interact with your panel. Click any button to edit:
                                                        
    
                                                            
  • Label - The text shown on the button (click directly to edit inline)
    • 
                                                            
  • Emoji - An optional icon displayed before the label
    • 
                                                            
  • Style - The button color (Primary, Secondary, Success, Danger)
    • 
                                                            
  • Link Buttons - These open a URL instead of creating a ticket
    • 
                                                        

                                                        
Each row can hold up to 5 buttons. You can have up to 5 rows of buttons and select menus combined.


                                                        Working with Select Menus
                                                        Select menus let users choose from a dropdown list. Click the menu or any option to edit:
                                                        
    
                                                            
  • Placeholder - The text shown before a selection is made
    • 
                                                            
  • Options - Each option has a label, optional description, and optional emoji
    • 
                                                        

                                                        
Each select menu can have up to 25 options. Drag options to reorder them.


                                                        Ticket Questions
                                                        Ticket Questions are prompts that appear when a user clicks a button or selects an option. They collect information before the ticket is created.
                                                        
    
                                                            
  • Short Text - Single-line text input for brief answers
    • 
                                                            
  • Long Text - Multi-line text area for detailed responses
    • 
                                                            
  • Mark questions as required or optional
    • 
                                                            
  • Add placeholder text to guide users
    • 
                                                        

                                                        
Questions are configured per button or option. Select a button/option to manage its questions.


                                                        Button & Option Configuration
                                                        Each button and select menu option has additional settings. For ticket panels:
                                                        
    
                                                            
  • Categories - Which channel categories can receive tickets
    • 
                                                            
  • Ticket Roles - Staff roles that can view and manage the ticket
    • 
                                                            
  • Ticket Pings - Roles to ping when a ticket is created
    • 
                                                            
  • Ticket Content - Custom message sent when ticket is created
    • 
                                                            
  • Required Roles - Roles users must have to use this option
    • 
                                                        

                                                        For application panels:
                                                        
    
                                                            
  • Application Type - Label for the type of application
    • 
                                                            
  • Reviewer Roles - Who can review and vote on applications
    • 
                                                            
  • Granted Roles - Roles given when an application is approved
    • 
                                                            
  • Roles to Remove - Roles removed when an application is approved
    • 
                                                            
  • Requirements - Minimum account age or server membership
    • 
                                                            
  • Cooldowns - How long users must wait to reapply
    • 
                                                        


                                                        Drag and Drop
                                                        Reorder elements by dragging them:
                                                        
    
                                                            
  • Rows - Drag the grip handle next to "Embed", "Buttons", or "Select Menu" to reorder entire rows
    • 
                                                            
  • Buttons - Drag buttons within a row to change their order
    • 
                                                            
  • Options - Drag select menu options to reorder them
    • 
                                                            
  • Embeds - Use the up/down arrows in the footer, or drag the grip handle
    • 
                                                        


                                                        Duplicating Components
                                                        Use the "Duplicate" button to copy an embed, button row, or select menu. This copies all settings, making it easy to create similar options quickly.
                                                        
    
                                                            
  • Duplicate is disabled when you've reached the maximum allowed
    • 
                                                            
  • Maximum 10 embeds
    • 
                                                            
  • Maximum 5 component rows (buttons + select menus combined)
    • 
                                                        


                                                        Adding Components
                                                        Use the buttons at the bottom of the preview to add new elements:
                                                        
    
                                                            
  • Add Embed - Creates a new embed card
    • 
                                                            
  • Add Button Row - Creates a new row of buttons
    • 
                                                            
  • Add Select Menu - Creates a new dropdown menu
    • 
                                                        

                                                        
Within button rows and select menus, use the ghost "+ Add" buttons to add more buttons or options.


                                                        Saving Your Changes
                                                        When you're done editing, click the Save button at the bottom of the screen to publish your changes. Your panel will be updated in Discord immediately.
                                                        
    
                                                            
  • Red highlights indicate validation errors that must be fixed before saving
    • 
                                                            
  • You'll be warned if you try to leave with unsaved changes
    • 
                                                            
  • Use the Cancel button to discard all changes and start over
    • 
                                                        


                                                        Quick Tips
                                                        
    
                                                            
  • Click directly on button labels in the preview to edit them inline
    • 
                                                            
  • Use link buttons for external resources like documentation or Discord invites
    • 
                                                            
  • Keep your panel organized with clear button labels and descriptions
    • 
                                                            
  • Test your panel by creating a test ticket to ensure everything works as expected
    •
